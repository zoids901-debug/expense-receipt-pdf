# 법인카드 영수증 자동정리

하이웍스 거래내역 표 + 영수증 사진을 A4 PDF로 자동 정리하는 웹 도구.

## 사용법
1. 하이웍스에서 거래내역 표 복사 → 앱에 붙여넣기 → **파싱**
2. 영수증 파일 또는 폴더를 드래그앤드롭 (또는 버튼으로 선택)
3. 미할당 영수증 썸네일을 표의 영수증 칸에 드래그해서 매칭
4. **PDF 생성 & 다운로드** 클릭

## 특징
- **설치 불필요** — 브라우저만 있으면 바로 사용
- **데이터 외부 전송 없음** — 모든 처리는 브라우저 내부에서
- **두 가지 입력 포맷 지원** — 탭 구분 표 / 줄 단위 리스트 자동 감지
- **자동 라벨링** — `4/23 메뉴개발비-빙수 샘플비 (호안끼엠)` 형식
- **A4 6칸 레이아웃** — 영수증 6장씩 한 페이지에
- **누락 영수증 표시** — 점선 placeholder

## 기술
- pdf-lib + fontkit (PDF 생성, 한글 폰트 임베드)
- pdf.js (입력 PDF 영수증 렌더링)
- Pretendard (한글 폰트)
- 순수 HTML/CSS/JS (의존성은 모두 CDN)

## 로컬 실행
```bash
# 그냥 index.html을 브라우저로 열면 됨
# 단, file:// 프로토콜에서는 일부 CDN 로딩이 막힐 수 있음 → 간단 서버 사용 권장:
python -m http.server 8000
# 그 후 http://localhost:8000 접속
```
